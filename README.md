# switchbackai/homebrew-tap

Homebrew formulae for [switchbak](https://switchbak.dev), the command-line client that carries AI coding agent sessions to switchback.

## Install

```bash
brew install switchbackai/tap/switchbak
```

Or tap first, then install by name:

```bash
brew tap switchbackai/tap
brew install switchbak
```

Requirements: macOS on Apple silicon (arm64).

## Set up

Installing puts the binary on your `PATH` but does not start anything. To watch the agent sessions on this Mac and load the launch agents, run:

```bash
switchbak setup
```

The formula has no `brew services` entry on purpose: `switchbak setup` writes the launch agents itself, with the host and endpoint they need.

Check the installed version with:

```bash
switchbak version
```

## Upgrade

```bash
brew upgrade switchbak
```

## Uninstall

Remove the launch agents before uninstalling, otherwise they are left behind:

```bash
switchbak teardown
```

```bash
brew uninstall switchbak
```

## Maintaining this tap

`Formula/switchbak.rb` is generated by `clients/macos/ci/release.sh` in the switchback repository, which also uploads the release zip to this repo's [GitHub Releases](https://github.com/switchbackai/homebrew-tap/releases). Don't edit the formula by hand; change the release script and cut a new release instead.
